Para obter imagens, o instalador precisa de acesso a um destes dois conjuntos de endpoints. ^1^ Os endpoints listados na opção 1 são recomendados porque são mais seguros. Recomendamos que você configure seu firewall para permitir os endpoints listados na opção 1, enquanto bloqueia os endpoints listados na opção 2. Observe o seguinte sobre esses endpoints:

* Os endpoints listados na opção 1 são suportados a partir da versão 3.9.47 do agente do Console. Não há compatibilidade com versões anteriores do agente do Console.
* O agente do NetApp Console contata primeiro os endpoints listados na opção 2. Se esses endpoints não estiverem acessíveis, o agente do NetApp Console contata automaticamente os endpoints listados na opção 1.
* Os endpoints da opção 1 não são compatíveis se você usar o agente do Console com NetApp Backup and Recovery ou NetApp Ransomware Resilience. Nesse caso, você pode desabilitar os endpoints listados na opção 1, enquanto permite os endpoints listados na opção 2.
