Faça login no Console e associe o agente do Console à sua organização. Como você faz login depende do modo em que está usando o Console. Se estiver usando o Console no modo padrão, faça login pelo site SaaS. Se estiver usando o Console no modo restrito ou privado, faça login localmente a partir do host do agente do Console.

.Passos
. Abra um navegador da web e insira a URL do host do agente do Console:
+
O URL do host do Console pode ser localhost, um endereço IP privado ou um endereço IP público, dependendo da configuração do host. Por exemplo, se o agente do Console estiver na nuvem pública sem um endereço IP público, você deve inserir um endereço IP privado de um host que tenha conexão com o host do agente do Console.

. Cadastre-se ou faça login.
. Após fazer login, configure o Console:
+
.. Especifique a organização do NetApp Console a ser associada ao agente do NetApp Console.
.. Insira um nome para o sistema.
.. Em *Você está executando em um ambiente seguro?* mantenha o modo restrito desativado.
+
O modo restrito não é compatível quando o agente do Console está instalado localmente.

.. Selecione *Vamos começar*.
