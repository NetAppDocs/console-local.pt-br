= Conecte seu LLM e habilite o assistente do NetApp Console na implantação local do NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Conecte um endpoint LLM compatível para disponibilizar orientações e operações de storage em linguagem natural controladas aos usuários de implantação local do NetApp Console.


NOTE: Esta documentação sobre como conectar um LLM ao assistente do Console para habilitar recursos de IA é fornecida como uma prévia da tecnologia. Com esta oferta de prévia, NetApp reserva-se o direito de modificar os detalhes, o conteúdo e o cronograma da oferta antes da Disponibilidade Geral.

.Funções de acesso necessárias
Superadministrador ou administrador da organização. link:reference-iam-predefined-roles.html["Saiba mais sobre funções de acesso"].

Após a configuração, os usuários abrem o assistente do Console no painel de controle e escolhem um modo de acesso:

* No modo *somente leitura*, o assistente responde a perguntas e fornece orientações sem fazer alterações.
* No modo *Leitura/Gravação*, o assistente pode operar na infraestrutura de storage. Ele exibe detalhes para revisão e confirmação antes de cada alteração. Para operações assíncronas, como a criação de volumes, ele cria uma tarefa que os usuários podem verificar no assistente.


Para conectar seu LLM, selecione um caminho de provedor, insira os detalhes do endpoint e a chave da API e, em seguida, selecione um modelo em *Administração > Ferramentas de IA*. As ações do assistente permanecem dentro das suas políticas de storage e dos controles de acesso baseado em funções.



[[gather-what-you-need-before-you-connect-an-llm]]
== Reúna tudo o que você precisa antes de conectar um LLM

Prepare as credenciais do provedor e o acesso ao endpoint para que o assistente do NetApp Console possa operar dentro dos limites de governança configurados em sua organização.

* Sua decisão sobre o tipo de provedor: OpenAI, OpenAI-compatible ou Anthropic, conforme suportado pela release e pelo endpoint.
* Uma chave de API válida para o caminho do provedor que você selecionar.
* A URL do endpoint para o caminho do seu provedor.
* Seu nome de usuário ou ID para a conta do provedor do LLM, se necessário.
* Acesso à rede a partir da implantação local do NetApp Console para o endpoint selecionado.


link:reference-llm-supported-models.html["Saiba mais sobre os provedores e modelos de LLM compatíveis na implantação local do NetApp Console"].



[[connect-an-llm-to-netapp-console-local-deployment]]
== Conectar um LLM ao NetApp Console em uma implantação local

Habilite as funcionalidades do assistente por meio de uma configuração de provedor validada, mantendo o controle administrativo sobre as credenciais do endpoint.

.Passos
. Faça login na implantação local do NetApp Console.
. Selecione *Administração > Ferramentas de IA*.
. Selecione o menu e, em seguida, selecione *Editar*.
. Em *Tipo de provedor*, selecione um tipo de provedor.
+
link:concept-llm-integration.html["Saiba mais sobre a integração do LLM na implantação local do NetApp Console"].

. Caso seja solicitado o endpoint do provedor, insira a URL do endpoint para o caminho do provedor que você selecionou.
. No campo *Nome de usuário*, insira seu nome de usuário ou ID de SSO se o caminho do seu provedor exigir isso.
. No campo *Chave de API*, cole a chave de API do seu caminho de provedor selecionado.
. Selecione um modelo da lista.
. Revise a configuração e selecione *Salvar*.
+
Revise o tipo de provedor, o URL do endpoint, a chave da API e o modelo selecionado antes de salvar a configuração.





[[verify-that-llm-integration-works]]
== Verifique se a integração do LLM funciona

Confirme a disponibilidade do assistente e o comportamento de aprovação para que os usuários possam confiar na integração configurada para operações governadas.

.Passos
. Abra o *Assistente de console* no modo *somente leitura* e execute uma consulta básica.
. Abra o *Assistente de console* no modo *Leitura/gravação* e confirme que as ações que alteram o armazenamento exigem confirmação do usuário antes da execução.
. Verifique se os usuários que precisam executar fluxos de trabalho têm os controles de acesso baseado em funções necessários.


Após concluir a validação, os usuários podem abrir o assistente do Console no painel e descrever tarefas em linguagem simples. link:task-console-asst-use.html["Saiba mais sobre o uso do assistente do NetApp Console"].



[[protect-credentials-and-monitor-llm-usage]]
== Proteja as credenciais e monitore o uso do LLM

Proteja as credenciais do LLM e monitore a atividade do provedor para reduzir o uso não autorizado da integração e apoiar a governança organizacional.

* Use uma chave de API dedicada para a integração de implantação local do Console sempre que possível.
* Gire as chaves de API de acordo com a política da sua organização.
* Monitore o uso da API do lado do provedor e os alertas de acordo com os requisitos de governança da sua organização.
